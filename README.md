# 商业财产保险理赔查勘与定损审核工作台

面向理赔员、专家与主管的商业财产险查勘工作台，覆盖损失科目、修复报价、残值、责任比例、准备金会签、争议项、附件版本和审计时间线。

## 技术栈

Angular + Angular Material + NgRx + Angular Router + HttpClient + RxJS + Angular CLI + TypeScript

## 本地运行

```bash
npm install
npm run start
```

访问 `http://localhost:62046`。

## 核心工作流

- 调整修复报价、责任比例或上传附件前先创建基线定损批次，锁定损失科目修订号、报价版本、证据版本和准备金。
- 保存时同一请求编号原子提交损失科目、准备金、附件版本和会签状态；首次响应丢失后安全重试，不重复追加附件、审计或准备金。
- 同一损失科目并发保存时只放行先到批次，后到批次返回被改对象并保留本地草稿，可基于最新版重建。
- 科目、报价、准备金或附件版本变化后，受影响的已完成会签立即失效，并从首个受影响档位重新会签。
- 历史案件自动补登 `INI-` 初始批次并保存快照，原始记录、附件版本和审计时间线仍可查询。
- 按案件和损失科目录入查勘事实、照片、报告与保单摘录。
- 准备金按金额与风险阈值触发多级会签，可退回补件。
